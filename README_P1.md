# 🔐 Password Strength Checker

**DecodeLabs Cybersecurity Internship | Project 1 | Batch 2026**

## 📌 About
A Python program that evaluates whether a password is Weak, Medium, or Strong based on security rules including length, character variety, and common password detection.

## 🎯 Features
- Checks password length
- Detects uppercase, lowercase, numbers, and special characters
- Flags commonly used weak passwords
- Gives a score out of 7 with detailed feedback
- Simple interactive menu

## 🛠️ Tech Stack
- Python 3
- `re` module (Regular Expressions)

## ▶️ How to Run
```bash
python password_checker.py
```

## 📊 Strength Ratings
| Score | Rating |
|-------|--------|
| 0–2   | 🔴 Weak |
| 3–4   | 🟡 Medium |
| 5–7   | 🟢 Strong |

String handling, condition checks, security basics, data validation
